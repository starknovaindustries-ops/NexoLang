# Roadmap da NexoLang

O roadmap é uma direção de desenvolvimento, não uma declaração de recursos já implementados.

| Versão | Meta |
|---|---|
| 0.1 | Lexer, parser, AST, variáveis, expressões básicas e saída |
| 0.2 | SE/SENAO, operadores lógicos e reatribuição |
| 0.3 | ENQUANTO, PARA e controle de laços |
| 0.4 | Funções e retornos |
| 0.5 | Listas, mapas, módulos e imports |
| 0.6 | Biblioteca padrão e operações com arquivos |
| 0.7 | Avaliar VM de bytecode e debugger |
| 1.0 | Especificação estável e integração planejada com NexoOS |

## Implementação inicial

O interpretador será desenvolvido inicialmente em Kotlin/JVM. Kotlin é a linguagem usada para construir o interpretador; os programas NexoLang serão escritos em arquivos `.nex`.
